# Portfolio

## Requirements

- Node.js 20.9 or later
- npm

## Setup

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```sh
npm run build
npm run start
```

## Quality checks

```sh
npm run lint
npm run format:check
npm run typecheck
npm test
```
